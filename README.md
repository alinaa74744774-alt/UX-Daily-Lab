# UX × English Daily Lab

这是一个基于 AI 自动化工作流的 UX 体验设计与英语学习项目。

## 项目目标

通过每日 UX 学习任务，将 UX 专业知识、专业英语、AI 与交互原型设计结合起来。

## 自动工作流程

学习计划
→ AI 生成每日 UX Challenge
→ UX 专业英语学习
→ 完成设计思考
→ Codex / WorkBuddy 制作交互原型
→ GitHub 保存学习成果
→ GitHub Actions 自动检查
→ 每周学习总结

## 每周学习计划

- 周一：用户研究 User Research
- 周二：用户画像 User Persona
- 周三：信息架构 Information Architecture
- 周四：用户流程 User Flow
- 周五：界面设计 UI Design
- 周六：交互原型 Prototype
- 周日：Weekly Review
